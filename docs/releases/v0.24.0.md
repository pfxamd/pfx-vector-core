# PFx Vector Core v0.24.0 — stabilization verification

Released from the v0.23 geometry engine after targeted hardening.

## Validation evidence

- Core/TypeScript/benchmark-build/WASM target CI: https://github.com/pfxamd/pfx-vector-core/actions/runs/37721483690
- Seeded 10,000-execution-per-target SVG and measure-index fuzz campaign: https://github.com/pfxamd/pfx-vector-core/actions/runs/37721483642
- Node.js WebAssembly runtime integration: https://github.com/pfxamd/pfx-vector-core/actions/runs/37721412921
- 1,000-cycle repeated curve-index construction and RSS stability: https://github.com/pfxamd/pfx-vector-core/actions/runs/37720759421
- Curved-path index scaling and peak-memory figures: https://github.com/pfxamd/pfx-vector-core/actions/runs/37720309204
- SVG parser/serializer-to-measure geometry regressions and numerical extremes are part of the core CI.

## Limits

The above evidence supports a bounded stabilization release, not a claim of complete mathematical robustness, security review, or browser/editor coverage. The fuzz campaign is short, rather than multi-hour; Node.js WASM smoke does not substitute for browser automation; SVG default serialization is lossy at 6 decimal places for nearly degenerate arcs; the TypeScript wrapper is private. Test target deployment conditions independently.
