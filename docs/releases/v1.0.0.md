# PFx Vector Core v1.0.0

Stable public Rust geometry kernel and SVG/WebAssembly/TypeScript integration boundary.

Verification evidence:
- Browser integration (Chromium, Firefox, WebKit): https://github.com/pfxamd/pfx-vector-core/actions/runs/37723316701
- Expanded browser geometry regression: https://github.com/pfxamd/pfx-vector-core/actions/runs/37722361151
- Bounded seeded fuzz tests: https://github.com/pfxamd/pfx-vector-core/actions/runs/37723614261
- Dependency security advisory scan: https://github.com/pfxamd/pfx-vector-core/actions/runs/37723686017
- Rust and TypeScript regression suite: https://github.com/pfxamd/pfx-vector-core/actions/runs/37723686030
- 1,000-cycle repeated-build memory soak: https://github.com/pfxamd/pfx-vector-core/actions/runs/37720759421

Limitations: test evidence is bounded; not all possible geometry inputs, external integrations, device configurations or adversarial conditions are covered. Default SVG serialization precision can affect nearly degenerate arcs. The TypeScript wrapper remains private. Rendering, scene graphs, application-level editor state and UI are out of scope.

Final release verification is enforced by the repository CI before GitHub Release publication.
